## T专家（dsh-expert）

给 DeepSeek Harness 用的专家名册：**22 个分类 / 623 位专家**，每位都有中文名与简介。

选中一位，它会以完整人格作为**子代理**跑一轮，把结果交回来。名册里 **22 个分类、623 位**专家全部随包分发，中文名与简介全量覆盖。

### 安装

**DSH Web / CLI**：

```bash
dsh plugin --profile web add dsh-expert
```

**DSH Desktop**：在**插件市场**里搜 `dsh-expert` 安装。

装完重启 DSH 生效。要求 DSH 宿主 `>=0.1.5-rc.1`。

### 怎么用

| 想做什么 | 怎么做 |
| --- | --- |
| 召唤一位专家 | 输入框打 `@` → 按分类挑一位 → 它作为引用 chip 进入本轮对话 |
| 让模型自己挑 | 直接说「让 XX 专家看看」，模型会调 `summon_t_expert` |
| 一次要多位 | 模型调 `summon_t_experts`（最多 8 位并行，部分失败仍返回成功的结果） |
| 看名册 / 建自己的专家 | 插件列表 → T专家 的**三个标签**：**专家**（看提示词、新建自建专家）、**分类**（自建分类增删改）、**技能**（模型可调用技能的开关） |

模型可调用的三个工具：

| 工具 | 作用 |
| --- | --- |
| `list_t_experts` | 列出已启用专家的分类与数量；传分类名可列出该分类的专家 |
| `summon_t_expert` | 召唤 1 位专家 |
| `summon_t_experts` | 并行召唤多位 |

### 界面入口

| 位置 | 是什么 |
| --- | --- |
| 插件列表 → T专家 | 管理面板，**三个标签**：**专家**（提示词 / 新建自建专家）、**分类**（自建分类增删改）、**技能**（技能开关） |
| 输入框 `@` | 按分类分组的专家菜单，选中即插入引用 chip |
| 输入区「T专家」按钮 | 浮层标签：**专家 / 技能**（默认停在**专家**）；分类只作分组，增删改请去插件信息页 |

### 数据与卸载

数据都在本机 `~/.t-team/`（名册、中文译文、你自建的专家），插件不连任何网络服务、不做遥测。卸载**不会**删这个目录，要清干净手动删即可。
