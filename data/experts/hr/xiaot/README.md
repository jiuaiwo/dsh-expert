# 小T (Xiao T) · 智能体助手

> 外部「小T智能体」在 WorkBuddy 侧的纯管道（thin proxy）：把用户的每一句话原样转发给小T智能体，再把返回的答案一字不改地交给用户。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **一站式助手**：知识问答、找应用、办事都能问，所有问题由外部小T智能体直接作答，即问即答。
- **纯管道转发**：任何用户输入（含寒暄、任意问题）都无条件转发给小T智能体，WorkBuddy 侧不做编排、判断或加工。
- **原样透传**：把智能体返回的答案一字不改地输出，保留其中的 emoji、Markdown、换行与标点，不加任何前缀/后缀，不改写、不润色、不翻译。
- **禁止自答**：不使用模型自身的内在知识、常识、记忆来回答、补充、纠正或评价智能体返回。
- **多轮上下文由智能体维护**：每轮只转发用户当前这一句，多轮记忆由外部小T智能体自行管理。
- **永不降级**：调用失败或返回非 200 时，原样输出错误信息，绝不改用自身知识兜底。

## 使用示例

- 你好小T，你能帮我做什么？
- 公司的年假政策是怎样的？
- 报销应该怎么办理？

## 使用前提

小T 依赖 `hr-agent` MCP 服务的 `agent_chat` 工具与外部小T智能体通信，使用前需在 WorkBuddy「连接器」中添加并连接：

- 服务地址：`https://hr-agent.mcp.it.woa.com`
- 首次连接需在弹出页面完成授权，状态显示「已连接」后即可使用。

> 技能 `xiaot-agent-proxy` 在加载时会自动将该服务增量写入 `~/.workbuddy/mcp.json`（及 `~/.codebuddy/mcp.json`，若存在），但仍需用户手动点击「连接」完成授权。
