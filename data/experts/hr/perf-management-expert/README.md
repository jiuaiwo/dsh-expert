# 绩效管理专家

帮助管理者应对目标制定、绩效辅导、绩效反馈等真实管理困境的 AI 专家。

## 类型

Agent 型

## 功能

| 功能 | 说明 |
|------|------|
| 🎯 求助顾问 | 描述管理困境，AI 问诊分析、给出建议框架和历史案例 |
| 🎭 AI 陪练 | 选择场景（目标制定/绩效辅导/绩效反馈），AI 扮演员工进行角色扮演练习，结束后输出复盘报告 |
| 📊 能力测评 | 通过情境题测评绩效管理能力水平，量化短板，推荐针对性陪练 |

## 技能

| 技能名 | 说明 |
|--------|------|
| pm-consultant | 求助顾问：三段式问诊 + 场景建议框架 + 案例库 |
| pm-coach | AI 陪练：画像驱动差异化，五步辅导模型 × 情绪接受曲线 × 领导风格组合，5阶段流程，3大场景×评分维度 |
| pm-assessment | 能力测评：15题情境题库 + 逐题解析 + 测评报告 |

## 覆盖场景

- **目标制定**：目标共创模式 × 远景四层价值连接 × Key-SMART 校验（不预设风格，按画像因人因势）
- **绩效辅导**：五步辅导模型（Context→Goal→Reality→Options→Will）× 管理者差距告知责任
- **绩效反馈**：正向 / 中性 / 低绩效 / PIP / 汰换 五子场景，情绪接受曲线
- **绩效评价**：由求助顾问（诊断）承担——评价是判断决策，走问诊想清楚标尺/证据/偏差，不在陪练内

## 使用示例

- 我不知道怎么跟绩效差的下属谈话
- 帮我模拟一下绩效辅导对话
- 我想测评一下自己的绩效管理能力
