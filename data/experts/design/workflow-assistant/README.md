# 流通通 — 流程编排专家（Fluent Flow）

汇金一站式流程编排专家：覆盖**流程设计**、**流程单操作**、**数据导出**三大领域，能智能识别「流程」与「流程单」的意图差异，并在每次回答末尾推送最精准的平台链接。底层由 `huijin-workflow` MCP 驱动，拆分为 10 个相互独立的技能。

## 专家信息

| 项目 | 内容 |
|------|------|
| 类型 | Agent 型（单专家） |
| 显示名 | 流通通（Fluent Flow） |
| 职业头衔 | 流程编排专家（Workflow Orchestration Expert） |
| 能力标签 | 流程设计、流程管理、流程单、审批操作 |
| 依赖 | `huijin-workflow` MCP（见 `.mcp.json`） |
| Agent 定义 | `agents/workflow-assistant.md` |

## 它能帮你做什么

专家的工作原则是：**识别意图 → 调用对应 Skill 执行 → 按操作类型选择「展示」或「二次确认」**。能力按领域划分：

### 领域 A：流程设计（看流程模板/图纸）
- 查询流程列表：我管理的流程（全量简报）、公开流程（按分类/状态/发起量筛选排序）。
- 查看流程画布详情：节点结构、输入字段定义。

### 领域 B：流程单查询（看申请/审批记录）
- 我的待办、我发起的流程单、单个流程单详情与审批进度、某个流程下的全部相关单据。
- 支持按状态、发起人、关键字、时间范围筛选，可导出 Excel 或生成统计简报。

### 领域 C：流程单变更（高风险写操作，均需二次确认）
- 审批（同意/拒绝/转办/前置加签/后置加签/参议）、撤单、增删改关注人。

### 领域 D：数据导出
- 查询单个流程单的字段填写值；批量导出某流程下所有流程单的输入字段值为 Excel。

## 技能一览（10 个）

| 技能 | 说明 | 典型触发词 |
|------|------|-----------|
| `query-workflow-list` | 查询流程列表（我的流程全量简报 / 公开流程按分类·状态·发起量筛选） | 我的流程、公开流程、有哪些流程、发起量最多的流程 |
| `query-workflow-detail` | 查看某流程（P 开头）的画布、节点、字段定义 | 流程详情、画布、图纸、流程配置 |
| `query-todo-instances` | 查询待我处理的流程单（可按发起人/状态/关键字筛选） | 待我处理、我的待办、需要我审批的 |
| `query-my-instances` | 查询我发起的流程单（可按状态/时间/关键字筛选） | 我发起的、我提交的、我的申请 |
| `query-instance-detail` | 查看某流程单（T 开头）详情、审批进度与历史 | 流程单详情、审批到哪了、审批进度 |
| `query-workflow-related-instances` | 查询某流程（P 开头）下所有相关单据，或批量提取字段 | 流程的单据、这个流程有哪些申请、批量导出字段 |
| `approve-instance` | 审批流程单（同意/拒绝/转办/加签/参议），**写操作** | 审批、同意、驳回、转办、加签、参议 |
| `revoke-instance` | 撤回一个进行中的流程单（仅发起人），**写操作** | 撤回、撤单、取消申请 |
| `update-instance-watcher` | 为流程单增删改关注人，**写操作** | 关注流程单、加关注人、抄送、取消关注 |
| `export-instance-fields` | 查询单条字段值，或批量导出某流程下字段为 Excel | 字段值、导出流程单字段、批量提取字段 |

## 使用方式

直接用自然语言描述需求即可，无需记 ID 规则。几个入门示例：

- 查询我待办的流程单列表
- 查询我管理的流程列表
- 查看流程单 `T2026051400014945` 的详情和审批进度
- 公开流程里计费平台、发起量最多的有哪些
- 把某个流程下所有流程单的字段导出成 Excel
- 帮我审批 `T...`（会先展示简报并等你二次确认）

> **ID 约定**：流程（模板）ID 以 `P` 开头，流程单（实例）ID 以 `T` 开头，任务节点 ID 以 `N` 开头。

### 智能术语消歧（重要）

用户常不区分「流程」和「流程单」，专家会按上下文自动判断：

| 你的说法 / 线索 | 判定为 | 说明 |
|----------------|--------|------|
| 出现 `T` 开头 ID、"审批到哪了"、"待办"、"我发起的" | 流程单 | 走流程单相关技能 |
| 出现 `P` 开头 ID、"画布"、"节点"、"图纸"、"配置" | 流程设计 | 走流程模板相关技能 |
| "审批单 / 审批单据" | 100% 流程单 | 铁律 |
| 仅说"流程"且无线索 | 主动澄清 | 会反问是「流程图纸」还是「流程单」 |

### 状态口径

- **流程模板状态**（流程列表）：用户可见 3 态——已启用（`Enable`）/ 已停用（`Disable`）/ 未启用（`Ready` 或 `Draft` 合并）。
- **流程单状态**（流程单列表/详情）：进行中（`Running`）/ 已完成（`Succeed`）/ 已失败或已驳回（`Failed`）/ 已撤回（`Revoked`）/ 待处理（`Pending`）。
- ⚠️ 两套状态不可混用。

### 安全约束

审批、撤单等**高风险不可逆操作**，专家必须先展示操作摘要 + 风险提示，并通过问答组件等待你明确确认后才会调用写工具；你选择取消则不做任何变更。
